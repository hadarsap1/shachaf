• "הוספת הורה שני" זמינה עכשיו לכל הורה, בהגדרות.

2️⃣ *הורי הגנים* - עדכנו את מספר הטלפון שלכם בהגדרות, ואז נקשר אליכם את הילדים ותוכלו לראות אותם באפליקציה.
