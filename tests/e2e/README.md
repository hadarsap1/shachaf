# בדיקות E2E

חבילת smoke שמריצה את האפליקציה האמיתית בדפדפן (Chromium) מול אמולטורים
מקומיים של Firebase — Auth ו-Firestore. הכול רץ מקומית: אין נגיעה בפרויקט
הפרודקשן ואין צורך במפתחות.

## הרצה

```bash
npm i -D playwright        # פעם אחת (או NODE_PATH להתקנה גלובלית)
npm run test:e2e
```

דרישות: Java (בשביל האמולטורים) ו-Playwright שניתן לטעון מ-Node.
אם הדפדפן המצורף ל-Playwright לא הורד, אפשר להצביע על בינארי קיים:

```bash
CHROMIUM_PATH=/path/to/chromium npm run test:e2e
```

## מה זה מכסה

| קבוצה | מה נבדק |
|---|---|
| דפים ציבוריים | מסך הכניסה, שלושת הדפים המשפטיים, הפניה של נתיב לא מוכר ושל מסך מוגן |
| הרשמה | הרשמה עם מייל וסיסמה, שער ההסכמה חוסם תוכן, אישור פותח את הדשבורד, רענון שומר סשן |
| משפחה שהוזמנה | נרשם עם מייל מהייבוא, לא מגיע לתוכן הקהילה, ולא עוקף דרך כתובת ישירה |
| הורה קיים | דשבורד, אירועים, אישור הגעה ששורד רענון, לוח משימות, וכל דפי הניווט |
| ממתין לאישור | חשבון בסטטוס `pending` לא רואה תוכן קהילתי |
| מנהל | מסך הניהול וכל תת-הדפים שלו |
| מובייל | 390×844 — כל מסך נבדק שאין בו גלישה אופקית |

בכל צעד נאספות שגיאות קונסול, שגיאות JS, ובקשות same-origin שנכשלו; צעד עם
שגיאה נחשב נכשל. שגיאות הרשאה מ-Firestore נאספות בנפרד ומודפסות בסיכום —
שם צפה באג לוח המשימות של אוגוסט 2026.

## מבנה

- `seed.mjs` — יוצר את המשתמשים באמולטור ה-Auth וזורע את הנתונים ב-Firestore
  (עם חוקי אבטחה מנוטרלים). התאריכים מחושבים יחסית ליום ההרצה.
- `run.mjs` — מרים שרת פיתוח עם `VITE_USE_EMULATORS=1`, מריץ את התרחישים,
  ומסכם. יוצא בקוד 1 אם משהו נכשל.
- `screenshots/` + `last-run.json` — תוצרי ההרצה האחרונה (לא נכנסים ל-git).

## הוספת תרחיש

```js
await step('שם התרחיש בעברית', async () => {
  await page.goto(`${BASE}/some-path`, { waitUntil: 'domcontentloaded' })
  await expectText(page, 'טקסט שחייב להופיע')
  assertClean('שם לדיווח')      // אין שגיאות קונסול/רשת בצעד הזה
})
```

שימו לב: משתמש בכניסה ראשונה מקבל את מסך ההדרכה כשכבה מעל הכול —
`dismissTutorial(page)` לפני כל לחיצה על תוכן הדף.
